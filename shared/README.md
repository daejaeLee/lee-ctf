# Shared CTF helpers

Put small, proven, reusable helpers here. Keep challenge-specific exploits in that challenge's `solve/` directory.

Suggested subdirectories are `crypto/`, `forensics/`, `pwn/`, `reverse/`, `web/`, `wordlists/`, and `payloads/`. Add a helper only after it has been useful in more than one challenge; this keeps first-pass search results small.
